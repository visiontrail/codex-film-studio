# Independent LiDAR Survey production

1. Read `STYLE.md`, `DIRECTOR.md` and `TECHNIQUE.md` in the generated project.
2. Fill `content/film.json` with the production brief, survey metadata, data
   permissions, measurement methods and frame-based cues.
3. Verify the coordinate frame, units, classification and dates against the
   source documentation. Preserve raw inputs and record processing steps.
4. Author the renderer and soundtrack for your subject. This starter has no
   dataset, invented measurements, example story or film renderer.
5. Review encoded frames, normal-speed motion and actual audio. Use the shared
   frame-review tools copied into the independent project and record actual
   review coverage.

Keep data, narration, generated media and review records in this project.
