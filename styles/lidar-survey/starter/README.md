# Independent LiDAR Survey production

Read STYLE.md, TOOLS.md and PRODUCTION.md. Run `npm ci`, then `npm run proof`
for an explicitly labelled two-second material diagnostic. Author new scenes in
`content/production.json` and `src/scene.mjs`, provide verified assets and audio,
and run `npm run build`. No previous story or cast is included.

For the original film's exact composition and inputs, use an external source
bundle; see `methods/reproduction.md`. A material proof is not a finished film
or evidence that a new production matches its reference.

Fill `content/film.json` with the survey metadata, data permissions and measurement methods before authoring the executable timeline. Verify coordinate frames, units, classification and dates against the source documentation. Preserve raw inputs and processing steps in this external project. No real dataset or measurements are supplied by the diagnostic.
