# Whiteboard working project

Read `STYLE.md` when present, otherwise `../STYLE.md`. The root repository's
`TECHNIQUE.md` describes the commands; working copies also include that guide.

Adapt `content/narration.json`, factual sources and `src/film.mjs` together.
The long example uses `editions/long/content/` and `src/long-film.mjs`.
Keep unique drawing IDs and one chronological queue per pen. Preserve the
shared timeline for picture, voice, captions and sound.

Generate or import WAVs, obtain independent timing, then validate and render.
Use draft mode only for development. Review representative stills and actual
motion before final encoding. Report actual review and listening coverage.

Keep generated media, private settings and dependency folders out of Git.
