# Prismatic Atlas

A reusable vocabulary for saturated vector science films: inhabited environments,
isometric volumes, clear mechanisms and purposeful changes of scale.

Authoring toolkit. The library contains no production narration, subject-specific
scene code, films, provider jobs or acceptance records. Each film is an independent
external project. The helpers do not create a finished story automatically.

The public page includes a complete English film, chapter navigation, captions,
a transcript, an interactive scale study and an Agent prompt entry. Story-specific
media and metadata are pinned Release assets described by `demo-assets.json`.
They are kept separate from the generic starter and methodology.
