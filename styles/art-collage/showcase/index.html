03 / YOUR NEXT FILM

New story.
Same scissors.

Bring a subject, an audience and a running time. Build a paper world that belongs to your story.

  1. 01

    Get the studio.

    Clone the repository, then run the project command from its root.

    git clone https://github.com/visiontrail/codex-film-studio.git
cd codex-film-studio
  2. 02

    Start with blank paper.

    Create an independent Art Collage project. Open the new folder in Codex.

    python3 scripts/new_film.py my-film --style art-collage
  3. 03

    Make it yours.

    Write the narration and scenes, choose the cast and materials, then build motion and sound together.

The starter includes blank inputs, paper tools and production guides. Author the scenes, renderer and audio for each new film.

04 / FROM THE CUTTING TABLE

Craft the details.
Keep the intent.

A clear method leaves more room for a distinctive film.

01

Cast for the story.

Keep a character recognisable across shots. For a specific real person, use a portrait supplied for that production; adapt the paper and print treatment around their identity.

02

One shared clock.

Use an integer-frame timeline for picture, narration, captions and sound. Give each object its own weight, and each important thought a readable hold.

03

Look. Watch. Listen.

Inspect encoded stills at useful sizes. Watch the movement and listen to the mix separately. Fix the observed defects and check the final delivery again.
