# Provenance and scope

The method and generic utilities were authored for Codex Film Studio. The project
acknowledges [lemo-opuscar](https://github.com/lemomo-ai/lemo-opuscar) as an influence
on director-led, iterative video creation. This package does not copy its scene
implementations or ship an upstream production.

The preview is a newly drawn abstract SVG style sketch, not a frame from a film.
No third-party footage, music, voice, character or generated production plate is
bundled. Future productions must keep their own source and licence ledger.

The tools use NumPy, OpenCV and Pillow when installed by a production. The tiny
JavaScript helper has no runtime dependencies. Dependency availability is not
proof that a film has been rendered or reviewed.

The standalone page adds an original generic SVG composition study. Jost is
redistributed under the SIL Open Font License, retained beside the font.
Published film media and its credits are separate, pinned Release assets.
