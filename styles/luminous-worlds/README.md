# Luminous Worlds

A reusable hybrid illustration and animation method for luminous graphic worlds.
Only methods, generic helpers and an empty contract are included.

Status: **toolkit-ready**. Author the story, drawings, performances, score and
sound in an external project. There is no bundled example film, production
narration, subject-specific composition, generation history or acceptance record.

The public page includes a complete English film, chapter navigation, captions,
a transcript, an interactive composition study and an Agent prompt entry.
Production media and metadata are pinned Release assets described by
`demo-assets.json`; they remain separate from the generic starter and methods.
