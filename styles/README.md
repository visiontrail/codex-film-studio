## What is complete / 已完成什么

- **whiteboard** — 已有短版、长版发布样片和可编辑渲染工程。 Released short and long samples with an editable renderer.
- **art-collage** — 已有空白输入、纸材工具和通用制作审查流程；需编写场景与渲染器。 Blank inputs, paper primitives and shared production/review guides; author scenes and renderer.
- **crayon-book** — 已有材质工具、输入合同和项目创建入口；场景、配音与渲染流程仍需编写。 Material tools and an input contract; project creation is available, scene and audio pipelines remain to be authored.
- **midcentury-cartoon** — 已有空白项目、套色与时间轴工具、制作和音频审查规范；需编写场景与渲染器。 Blank inputs, print/timeline helpers and style-specific workflow, audio and review guides; author scenes and renderer.
- **satellite-briefing** — 已有空白项目、地理计算工具、实拍与审查流程；需编写影像渲染与剪辑。 Blank inputs, geographic helpers and footage/review guides; author imagery renderer and edit.
- **scifi-sitcom** — 已有空白项目、描边与时间轴工具、制作和审查流程；需创作角色、场景与渲染器。 Blank inputs, ink/timeline helpers and workflow/review guides; author cast, scenes and renderer.
- **microgame** — 已有独立材质与动作工具；镜头、音频和交付需在制作项目中完成，暂无已验收样片。 Independent material and motion helpers; scene direction, audio and delivery require production-specific work. No accepted demo.
- **art-deco** — 已有独立绘制工具、人物骨架与空白输入合同；新场景、旁白与渲染器仍需编写。 Original drawing and figure toolkit with a blank input contract; new scenes, narration and renderer must be authored.
- **caption-news** — 已有空白输入、确定性字幕动效工具和通用方法；需为新选题编写场景、渲染与音频。 Blank authoring inputs, deterministic caption helpers and shared methods; author new scenes, renderer and audio.

`demo-ready` includes a released sample and editable renderer. `starter-ready`
provides blank authoring inputs, guides and helpers. `toolkit-ready` provides
material tools and an input contract. All three support the same creation command;
none describes the acceptance of a new production.

## Use any style / 统一使用方式

```sh
python3 scripts/new_film.py --list
python3 scripts/new_film.py my-film --style <id>
python3 scripts/new_film.py my-film --style <id> --output /absolute/external/path
```

Commands run from the repository root. Open the resulting project in Codex
and supply the topic, audience, language and duration. Existing output directories
are preserved. New productions belong outside this library.

## Open existing pages / 打开已有网页

```sh
python3 scripts/serve_styles.py --port 8249
```

Open http://127.0.0.1:8249/ for the catalog and its showcase links.
The HTML entrypoints are in each style package. Local showcases read media,
fonts and review data from the retained projects listed in `styles.json`.
A fresh clone without those projects shows their missing-resource status.
Whiteboard uses its existing Release download workflow. Local pages are not
automatically published or copied into new-film starters.

## Previous paths / 旧路径

The five former `methods/<style>/` packages moved to `styles/<style>/`.
Use `scripts/new_film.py --style <id>` for all of them. `--method <id>` remains
a deprecated command-line alias. Existing external projects are independent
copies and retain their original files. Shared methods now live in [methods/](../methods/README.md).
