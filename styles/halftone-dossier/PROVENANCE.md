# Provenance

The print, case-file and motion vocabulary is informed by
[LemoLab's Halftone Dossier](https://github.com/lemomo-ai/lemo-opuscar/tree/main/styles/halftone-dossier).
The upstream repository uses the MIT License, copyright 2026 LemoLab.

This package contains a rewritten generic style guide, empty authoring inputs
and an original bilingual showcase page. The interactive print study uses
HTML/CSS/SVG and contains no sample story. Published film metadata, captions,
credits and media are supplied separately by the checksum-pinned Release bundle.
No source portrait, provider credentials or provider job records are included.

The English sample's visual and audio review limits are described in its media
credits. Publication is separate from an assertion of exact style reproduction.
