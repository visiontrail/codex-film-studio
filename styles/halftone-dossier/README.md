# Halftone Dossier / 复古半调案卷

Warm paper, spot-ink dots, offset headlines and physical stamps turn a story into
a sequence of exhibits. Explore the [independent style page](https://visiontrail.github.io/codex-film-studio/styles/halftone-dossier/showcase/index.html),
including a complete English-narrated sample, visual grammar and an interactive
print study. Page explanations support English and Chinese; the film stays English.

Status: **starter-ready**. This package includes a [style guide](STYLE.md),
[prompt](prompt.txt) and [empty input contract](starter/content/production.json).
It does not include a general scene renderer or the sample's editable production.
The sample is a separate publication, with review limits recorded in its credits.

Open the studio in your coding Agent and ask:

> Use halftone-dossier to make a [duration] film about [subject] for [audience],
> with narration and captions in [language]. Handle project creation, environment
> setup, authored scenes, sound and review. Deliver the MP4 and editable project.

在 Agent 中打开工作室，描述主题、观众、时长与语言。Agent 自动创建外部工程，
重新创作场景与声音，检查并交付视频。精确重建已有样片需要先取得其源工程和素材。

See [provenance](PROVENANCE.md) and the [shared production workflow](../../methods/README.md).
