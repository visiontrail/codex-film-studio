# Add a film style

Create `styles/<slug>/` with `STYLE.md`, `prompt.txt`, `DEMO.md`, a poster and
an editable `studio/` template. Add its relative paths to `styles.json`.

The guide should describe its visual and sound language, what can vary, and
what makes it recognizable. Ship a real rendered example and document the
commands and required inputs. Keep large demo media in Releases with hashes.
Keep original audio and any private production records outside Git.

The template must run without the author's parent repository or private
services. If narration requires a service, document the contract and provide
a recorded-audio path. Retain licenses for fonts, samples and reference films.

Verify a clean checkout, a short render and the public download links before
listing a style as available. Add styles independently; do not change another
style's approved demo while adding your own.
