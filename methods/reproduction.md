# Make a new film or recreate an existing sample

The user can start either workflow with a natural-language brief. The Agent
handles project creation, environment preparation, production and review in the
same conversation. Keep every production outside this library.

## A new subject in a chosen style

Read the style's registry entry and guides. Create an independent working copy
with `scripts/new_film.py NAME --style ID`, then install the dependencies
documented by that project. Author the new narration, drawings, scenes, camera
and sound together. A toolkit or starter may require a new renderer; the Agent
does that work rather than passing coding tasks back to the user.

## The same original sample

First identify the requested sample and edition from its title or link. Check
for its original composition, source imagery, recorded audio, alignment, fonts,
dependency locks and timeline. Use verified original inputs when available.
The released whiteboard inputs can be retrieved with `scripts/fetch_demo.py`;
follow the existing composition and the README's Agent rebuild reference.

For other samples, locate the retained source project or an available source
bundle. Preserve the original and work in an independent external copy. Follow
its recorded setup and rendering instructions, verifying recorded checksums
where provided. A showcase archive containing MP4s is not an editable project.
If source files, licensed assets or service access are missing, name the exact
gap and request only what is needed. Do not invent a download location, replace
the original composition with a generic proof, or claim an exact recreation of
a newly authored film. Encoder and platform differences can change output bytes.

## Review and delivery

Inspect representative rendered stills and motion, then check the final MP4.
Record technical validation, visual inspection and actual listening separately.
Repair observed defects and deliver the MP4 with editable sources and the actual
review scope. Preserve existing projects and published examples. Making a local
film does not authorize publication.
